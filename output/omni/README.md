# Omnintellx — Omni Output Deliverables

This directory contains the production release outputs generated by Omnintellx Studio:

## 1. Standalone Web Applications
- **`index.html`**: Production standalone single-file web application. Run in any modern desktop or mobile browser.
- **`standalone.html`**: Dual-mirrored offline-ready build.

## 2. Android 9 (API 28) Package
- **`omnintellx.apk`**: Installable Android package configured for Android 9 Pie (API 28) and newer.
- Source and full Gradle project available in `/android/`.

## 3. Hosting & PHP Admin System
Located in `/hosting/`:
- **`admin.php`**: Self-hosted administrative control panel for token quotas, per-user API rate limits, and key restrictions. Default password: `omnintellx2026!`
- **`api_proxy.php`**: Quota and rate-limiting enforcement gateway.
- **`config.json`**: JSON-backed user accounts ledger and provider API keys.

## 4. Verification & Metadata
- **`build-manifest.json`**: Complete deliverable catalog and size verification.
- **`test-report.json`**: Verification test suite results.
